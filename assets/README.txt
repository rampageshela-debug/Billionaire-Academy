Put your own assets in this folder:

- logo.png                 Your academy logo (optional; current site uses text logo)
- academy-hero.jpg         Academy page hero image
- course-guide.pdf         Student course PDF download
- certificate.pdf          Certificate PDF/template
- bot-session.jpg          Image for Session Sniper bot template
- bot-structure.jpg        Image for Structure Pro bot template
- bot-portfolio.jpg        Image for Portfolio Guard bot template

To show bot images, add CSS background-image URLs to .one, .two, and .three in style.css.
For real user accounts and email verification, connect the forms in script.js to Firebase Authentication, Supabase Auth, or a secure custom backend. Never store passwords in browser JavaScript.
